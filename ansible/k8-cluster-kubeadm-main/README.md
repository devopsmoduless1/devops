# K8 Cluster Ansible

## Description
 This is a Ansible playbook which creates kubernetes Master and worker nodes.</br>
 This play book was written to create Kubernetes cluster in On premises from scratch using kubeadm </br>
 This was Created to target specific client project where there is not a robust infrastructure

Note: We can also create K8's cluster using Terraform Modules </br>
Variable values are stored in Gitlab Pipeline variables
